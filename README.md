Проект: Адаптивное погодное веб-приложение (Telegram Mini App)

Разработанное приложение — это не просто виджет погоды, а полноценный интерактивный инструмент с современным дизайном. Вот его главные преимущества:

    Адаптивный интерфейс и атмосфера (UI/UX): Приложение автоматически подстраивается под время суток (утро, день, вечер, ночь) и погодные условия (снег, дождь, ясно). Зимой фон меняется на темный уже с 16:00, а при снегопаде на экране появляется легкая анимация падающего снега.

    Интерактивная шкала времени: Вместо статичного прогноза реализован кастомный ползунок. Пользователь может «перемотать» время на 24 часа вперед, чтобы посмотреть температуру, осадки и смену иконок в любой момент дня.

    Интеграция с Telegram (Mini App): Благодаря хостингу на GitHub Pages и подключению к BotFather, приложение работает как полноценный Telegram Mini App. Оно открывается в один клик прямо в мессенджере, не требует установки APK-файлов и не содержит рекламы.

    Точная геолокация: Используется API геолокации и обратный геокодинг (BigDataCloud). Приложение само определяет город пользователя (например, "Тюмень") и убирает лишний административный мусор из названия.

    Экономия ресурсов: Приложение полностью написано на нативном HTML/CSS/JS. Ему не требуется тяжелый фреймворк или серверная часть. Все запросы к погоде идут напрямую через бесплатный Open-Meteo API.

🇬🇧 In English

Project: Adaptive Weather Web App (Telegram Mini App)

This application is more than just a weather widget; it is a fully interactive tool with a modern design. Here are its key advantages:

    Adaptive Interface & Atmosphere (UI/UX): The app automatically adjusts its theme based on the time of day (morning, afternoon, evening, night) and weather conditions (snow, rain, clear). In winter, the background switches to dark mode as early as 4:00 PM, and a subtle snowfall animation appears on the screen when it's snowing outside.

    Interactive Time Slider: Instead of a static forecast, a custom slider is implemented. Users can "rewind" time up to 24 hours ahead to check the temperature, precipitation, and icon changes at any time of the day.

    Telegram Integration (Mini App): Thanks to GitHub Pages hosting and BotFather integration, the app works as a full-fledged Telegram Mini App. It opens in one click directly inside the messenger, requires no APK installation, and is completely ad-free.

    Precise Geolocation: It utilizes the Geolocation API and reverse geocoding (BigDataCloud). The app automatically detects the user's city (e.g., "Tyumen") and cleans up unnecessary administrative text from the name.

    Resource Efficiency: The app is built entirely on native HTML/CSS/JS. It does not require a heavy framework or a backend server. All weather requests are made directly through the free Open-Meteo API.
